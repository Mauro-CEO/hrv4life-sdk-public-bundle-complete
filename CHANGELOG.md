## 1.0.0

* HRV measurement via camera PPG with real-time finger detection.
* `HrvMonitorController` reactive API (`ValueNotifier` + immutable state).
* `HrvCameraPreview` widget with customizable placeholder, size and border radius.
* Calibration phase with signal-quality suggestions (`onSignalQualitySuggestion`).
* API integration (`X-API-KEY` / `X-Patient-Key`) for HRV analysis, groups and readings.
* `HrvResult` with summary, quality, metrics, visualization, training readiness,
  feedback messages, recovery score and training zones.
* Multi-locale controller messages (pt/en).
